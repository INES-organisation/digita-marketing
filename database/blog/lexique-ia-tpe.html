Les bases

Intelligence artificielle (IA)

Un programme capable de faire des tâches qu'on pensait réservées aux humains : comprendre une phrase, reconnaître une image, rédiger un texte. Le correcteur orthographique de votre téléphone en est une forme ancienne.

IA générative

Une IA qui produit du contenu nouveau (texte, image, son, vidéo) à partir d'une demande. C'est la famille de ChatGPT, Gemini, Claude, Mistral ou Copilot. Exemple : « Rédige une publication Facebook pour annoncer nos horaires de fin d'année. »

Modèle de langage (LLM)

Le « moteur » d'une IA générative de texte, entraîné sur d'énormes quantités d'écrits pour prédire la suite la plus probable d'une phrase. LLM vient de l'anglais large language model. Quand on vous dit qu'un outil « utilise GPT » ou « utilise Mistral », on vous parle du modèle qui tourne derrière.

Entraînement

La phase où le modèle apprend, à partir de millions de textes ou d'images. Pour vous, la vraie question est : mes conversations servent-elles à entraîner le modèle ? Beaucoup d'outils permettent de le désactiver dans les paramètres.

Prompt

La consigne que vous écrivez à l'IA. Plus elle est précise (qui vous êtes, pour qui, quel ton, quelle longueur), meilleur est le résultat. « Écris un mail » donne un texte banal ; « Écris un mail court et chaleureux à une cliente de Saint-Pierre pour confirmer son rendez-vous de mardi 9 h » donne un texte utilisable.

Les outils

Chatbot

Un programme qui discute par écrit avec vos clients, sur votre site, Messenger ou WhatsApp. Les anciens chatbots suivent un arbre de questions fixe ; les plus récents utilisent un modèle de langage et répondent avec leurs propres mots.

Agent IA

Un assistant qui ne se contente pas de répondre : il agit. Il peut consulter votre agenda, réserver un créneau, créer une fiche contact, envoyer un SMS. Notre article sur l'agent IA qui répond 24 h/24 détaille ce que ça change pour une TPE.

Automatisation

Un enchaînement de tâches qui se déclenche tout seul : un formulaire reçu crée une fiche client, envoie un accusé de réception et prévient le gérant. Une automatisation n'a pas forcément besoin d'IA, et c'est souvent là qu'on gagne le plus de temps.

API

Une « prise » qui permet à deux logiciels d'échanger des informations sans intervention humaine. C'est grâce aux API que votre formulaire de site peut écrire dans votre tableur ou votre logiciel de devis.

CRM

Le fichier client organisé de l'entreprise : qui sont vos prospects, où en est chaque devis, quand relancer. Un tableur bien tenu est déjà un petit CRM.

Base de connaissances

L'ensemble des informations que vous donnez à un chatbot ou à un agent pour qu'il réponde juste : tarifs, zone d'intervention, horaires, questions fréquentes. Un agent IA ne vaut que ce que vaut sa base de connaissances.

Les risques

Hallucination

Quand l'IA invente une information avec assurance : un faux prix, une loi qui n'existe pas, une référence imaginaire. C'est la raison pour laquelle tout texte produit par une IA doit être relu avant d'être envoyé à un client.

Biais

Les préjugés que l'IA reprend des textes sur lesquels elle a appris. Ils peuvent se glisser dans une offre d'emploi, une description de client type ou une image générée.

Données personnelles

Toute information qui permet d'identifier une personne : nom, téléphone, adresse, photo, numéro de dossier. Elles ne doivent pas être collées dans un outil d'IA sans savoir où elles sont stockées et à quoi elles servent.

Deepfake

Une image, une voix ou une vidéo truquée par IA pour imiter une personne réelle. Pour une entreprise, le risque le plus courant est l'arnaque : un faux appel du « gérant » qui demande un virement urgent.

Les règles

RGPD

Le règlement européen qui encadre l'usage des données personnelles. Il s'applique aussi quand vous utilisez une IA : informer vos clients, limiter les données collectées, choisir des outils qui les protègent. La CNIL publie des fiches pratiques sur le sujet.

AI Act (règlement européen sur l'IA)

Le texte européen qui classe les usages de l'IA selon leur niveau de risque. Pour une TPE, l'obligation la plus concrète est la transparence : une personne qui échange avec un chatbot doit savoir qu'elle parle à une machine, sauf si c'est évident. Cette règle de l'article 50 s'applique à partir du 2 août 2026.

Transparence

Dire clairement quand un contenu ou une réponse vient d'une IA. En pratique : « Bonjour, je suis l'assistant automatique de l'entreprise. » Les clients l'acceptent très bien quand la réponse est utile.

Humain dans la boucle

Le principe selon lequel une personne valide ce que l'IA propose avant que ce soit envoyé ou décidé : un devis, une réponse à une réclamation, un refus. C'est la meilleure protection contre les hallucinations.

Souveraineté des données

La question de savoir où sont stockées vos données et sous quel droit. Certains outils hébergent en Europe, d'autres aux États-Unis. Pour des données sensibles (santé, juridique), c'est un critère de choix.

Exemple (cas fictif) : le vocabulaire en situation

Une gérante d'institut de beauté à Saint-Denis veut répondre plus vite sur Instagram. Le prestataire propose un agent IA branché par API sur son agenda, avec une base de connaissances (soins, prix, durée). L'agent se présente comme assistant automatique (transparence), et les demandes inhabituelles lui sont transmises (humain dans la boucle). Elle sait désormais quelles questions poser.

Questions fréquentes

Quelle est la différence entre un chatbot et un agent IA ?

Un chatbot répond aux questions. Un agent IA répond et agit : il peut réserver un rendez-vous, créer une fiche client ou envoyer un SMS, en se connectant à vos outils.

Faut-il savoir programmer pour utiliser l'IA ?

Non. Les outils comme ChatGPT s'utilisent en écrivant des phrases normales. La programmation n'intervient que pour relier l'IA à vos logiciels, ce qu'un prestataire peut faire pour vous.

Que veut dire « l'IA hallucine » ?

Cela signifie qu'elle invente une information fausse en la présentant comme vraie. Il faut donc toujours vérifier les chiffres, les noms et les références qu'elle donne avant de les utiliser.
